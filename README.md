## What this is

A scratch repository. It holds two standalone HTML pages, `index.html` and
`main.html`, with no build step, no dependencies and no framework.

There is no larger project behind it. If you are looking for finished work, the
other repositories under this account are the place to look.

## Running it

Open either file in a browser. That is the whole procedure.

```bash
# or serve the folder if you prefer a real origin
python -m http.server 8000
```
